# DESIGN.md reference library

Source: github.com/VoltAgent/awesome-design-md (MIT, see LICENSE). Each file in `designs/` is a plain-markdown analysis of one brand's public marketing site: color tokens, type scale, spacing, radii, components, layout and motion rules.

## How to use

1. Pick the file(s) that match the request: `designs/<brand>.md`. Read the whole file before designing.
2. Treat it as inspiration for tokens, rhythm and component treatment, not as a template to clone. Never copy another brand's logo, name, wordmark, product imagery or proprietary assets.
3. On this repo (Hana Gallery, a Persian RTL jewelry shop) keep the Hana Gallery brand (cream / espresso / gold palette, its logo, Persian copy, RTL layout) unless the user explicitly asks to change it. Borrow structure, spacing, type hierarchy and motion ideas, then map them onto Hana Gallery's own tokens.
4. Latin-only font choices in a reference need a Persian-capable counterpart (for example Vazirmatn or Sahel for body text).
5. Tell the user which reference file(s) you drew from.

## Good starting points for a jewelry / luxury shop

- Premium, restrained: `apple`, `tesla`, `bmw`, `ferrari`, `lamborghini`, `bugatti`
- Warm consumer retail: `airbnb`, `starbucks`, `nike`, `pinterest`, `shopify`
- Editorial / magazine: `wired`, `theverge`, `notion`
